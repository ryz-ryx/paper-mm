# Phase 1 diagnostics (dev data only; exploratory / post-hoc)

Generated by `analysis/assemble.py` from `paper_mm2/data/{trades,quotes,queue_depleted,pending}.csv`. Every table below is produced by
code in this directory; the prose is hand-written. `engine.py`, `reporter.py` and `phase1_preregistration.md` were **not modified**.

## Read this first

- **Sample is tiny.** The clean-epoch data covers about 39 minutes of 2026-10-08 (06:43-07:22 UTC, 9 five-minute blocks): **241 primary fill
  rows = 161 distinct fill events**, all on Hyperliquid (12 instruments). Arms are nested (every B fill and every C fill is also an A fill,
  verified below), so arm rows are not independent samples and must never be pooled. Binance produced **no quotes and no fills**.
- **Nothing here is a registered test.** Every cell, bucket and split is exploratory and post-hoc, counts against no pre-registered
  alpha, and cannot pass or fail an arm. Dev stop-check status is unchanged: no arm has the 1,000 fills the rule needs.
- **Data window.** Only rows between the clean-epoch cutover (2026-10-08T06:40:17Z) and the dev end (2026-10-11) are loaded (`common.py`
  asserts this). The hold-out (2026-10-12 to 2026-10-15) has not started and is never read; `data_prefix_20261007/` is excluded as per Amendment 1.
- CIs are 5-minute block bootstraps (10,000 resamples, seeded) as pre-registered; with 9 blocks they are optimistic.

## Bugs and deviations found

No arithmetic bug (item 5). The following are deviations from the pre-registration text or properties that limit what the data can show;
none was changed (engine, reporter and pre-registration are read-only for this task, and any strategy-affecting change needs a new amendment).

| ID | Where | Finding | Effect | Evidence |
|---|---|---|---|---|
| D1 | `engine.py` `_manage_side_quote`, called only from `update_quote_logic` | "Requote every 1 s" is evaluated only when a book update arrives (no timer). Quotes at an unchanged touch stay live until the next update. | Quote age at fill: median 2.9 s, max 5.8 s; 83% older than 1.5 s. Differs from the pre-registered 1 s requote description; no edge dependence on age seen. | latency table |
| D2 | `models.py` `get_10s_realised_vol` | Computed from consecutive book updates (event time), not 1 s returns as its docstring says. | `realised_vol_10s` = 0 on 99.2% of fills, so the reporter's volatility terciles (pre-registered PASS criterion) are not meaningful. | verify table |
| D3 | `engine.py` lines ~457-460, `models.py` lines ~68-76 | Cancel-on-flow is skipped whenever the rolling 80th percentile is 0, and that percentile is sampled only in seconds with a trade. | Arm C is almost identical to B: 39 vs 41 fills; only 2 of 41 B fills had non-zero adverse flow. The C-vs-B filter-value test cannot pass. | filter-value table |
| D4 | `engine.py` `log_queue_depleted` | Queue-depleted events are written with blank mids / exit / edge (by design, Amendment 1). | The secondary fill-model comparison has no outcome data. | item 3 table (a) |

## Suggestions (for a future amendment; not applied)
